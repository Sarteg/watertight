# Code of conduct

Be kind and be useful. Treat everyone with respect. No harassment, no personal attacks, no
discrimination. Give feedback on the work, not the person. Assume good intent and ask when you
are unsure.

Maintainers may remove comments, commits or issues that break these rules, and may block people
who keep breaking them. To report a problem, open an issue marked "conduct" or message the
maintainer through their GitHub profile.

This text is a short, plain statement. If the project grows, it can move to the Contributor
Covenant.
